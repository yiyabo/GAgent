    创建账号

  3. 03

    配置客户端，开始提问

    选择右侧客户端的接入方式。完成后试试：“用 PhageAgent 查询噬菌体 NC_001416.1。”

在终端设置令牌，再安装插件：

export PHAGEAGENT_MCP_TOKEN='替换为你的令牌'
codex plugin marketplace add yiyabo/phageagent-mcp
codex plugin add phageagent@phageagent

令牌通过环境变量读取。请使用支持插件命令的 Codex 版本；其他版本可按客户端文档配置远程 MCP。

在终端安装插件，并按提示配置令牌：

claude plugin marketplace add yiyabo/phageagent-mcp
claude plugin install phageagent@phageagent
claude plugin configure phageagent@phageagent

配置时输入第二步创建的个人令牌。此方式适用于支持插件配置命令的 Claude Code 版本。

适用于支持远程 HTTP MCP 的客户端：

{
  "mcpServers": {
    "phageagent": {
      "url": "https://phageagent.deepomics.org/mcp",
      "headers": {
        "Authorization": "Bearer ${PHAGEAGENT_MCP_TOKEN}"
      }
    }
  }
}

先设置 PHAGEAGENT_MCP_TOKEN 环境变量。变量替换语法因客户端而异，请以客户端文档为准。

GOOD TO KNOW

开始之前。

遇到问题？
联系 PhageAgent 团队 ↗

需要在本地部署数据库吗？+

不需要。PhageAgent MCP 是远程服务，客户端通过 HTTPS 调用。你的 Agent 需要支持 Streamable HTTP；仅支持 stdio 的客户端可参考接入文档使用桥接。

数据查询与分析任务有什么区别？+

数据工具只读访问 PhageScope 参考数据库，包括已有注释和结构链接，并不代表预测了新结构。分析工具则把需求交给 PhageAgent 异步执行；返回任务 ID 后，可以继续查询进度和获取交付物。

谁可以使用？有什么额度？+

任何人都可以注册账号并创建令牌，每个令牌可使用全部 19 个工具。每个令牌每天最多读取 2 GB 数据，测试阶段分析任务暂无配额；查询仍有分页与单次返回限制，服务也可能返回请求过多的提示。

令牌和分析数据如何处理？+

不要公开个人令牌。本介绍页不接收令牌，也不直接执行分析。MCP 服务会记录调用审计信息；提交的分析需求与输出保存在服务端，需求会发送给 PhageAgent 使用的模型提供方。完整保留与共享规则见隐私政策。
