# 运行容器的「实际依赖快照」——不是清单，是事实记录
#
# 来源：2026-09-26 在 .8 上对 `docker exec phage-agent pip freeze` 与
# `phage-agent-runtime:qwen-v2` 镜像内 `pip freeze` 求差，得到 19 个
# **镜像里没有、但生产容器里装着**的包。它们历史上是直接 pip install 进容器的
# （本项目的既有惯例：能不重建镜像就不重建）。
#
# 为什么要落成文件：直接用镜像重建容器会**静默丢掉这 19 个包**，其中一半是
# 功能性依赖——openpyxl 管 .xlsx、pyarrow 管 parquet、scikit-learn 管 ML 任务、
# mplfonts/fontmeta 管 matplotlib 的 CJK 字体。所以 deploy/Dockerfile.runtime-overlay
# 会把这份文件装进去，让新镜像成为运行容器的忠实替身。
#
# ⚠ 这 19 个包里有相当一部分**本该进 requirements.txt / pyproject.toml**（pyarrow
# 与 scikit-learn 的缺席此前已被记录为已知缺口）。这里先只保证"镜像追上生产事实"，
# 把它们并入正式依赖清单是独立决策（会影响 byoryn 平台那套镜像），留待拍板。
